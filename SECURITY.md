# Security

Please report security problems privately, not in a public issue: use **Security > Report a vulnerability** in this repository. Include the page or file, what an attacker could do, and the steps to reproduce.

Only the live site is supported: https://assistant-api.assistant-service.workers.dev (Cloudflare Worker `assistant-api`). API keys live only on Cloudflare as Worker secrets; never paste one into an issue or pull request.
